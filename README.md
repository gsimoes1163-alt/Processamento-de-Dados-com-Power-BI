Desafio de Projeto

Neste repositório, apresento o desafio atendido em um arquivo imagem em JPEG (como "Dashboard - Desafio de Projeto.jpg") e outro arquivo no Power BI Desktop (como "company_desafio_mysql.pbix"), onde estes estão na pasta "AULA 4 - Processamento de Dados com Power BI"

Considerando as premissas deste desafio seguem as atividades desenvolvidas, na ordem:
- coleta de dados
- transformação via Power Query
- criação de um relatório via Power BI desktop
- publicação do relatório
- e inserção em um dashboard via Power BI online

  Na transformação dos dados foram atendidos os seguintes pontos:
  -	Verificado os cabeçalhos e tipos de dados
  - Modificados valores monetários
  - Verificado a existência dos nulos e analise a remoção
  - Verificado o número de horas dos projetos
  - Separado colunas complexas
  - Mesclado consultas employee e departament para criado uma tabela employee com o nome dos departamentos associados aos colaboradores. Neste processo eliminou-se as colunas desnecessárias. 
  - Realizado a junção dos colaboradores e respectivos nomes dos gerente.
  - Mesclado as colunas de Nome e Sobrenome para
  - Mesclado os nomes de departamentos e localização.
